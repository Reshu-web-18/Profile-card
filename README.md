# Profile-card
# 👤 Profile Card UI Design

A modern and responsive Profile Card UI created using HTML and CSS. This project showcases a stylish user profile card with a profile image, social media icons, action buttons, and user engagement statistics.

## 📌 Features

- Modern Profile Card Layout
- Responsive Design
- Circular Profile Image
- Social Media Icons
- Subscribe and Message Buttons
- Like, Comment, and Share Statistics
- Box Shadow and Rounded Corners
- Clean User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 📂 Project Structure

```
Profile-Card-UI/
│── index.html
│── window.png
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `window.png` is in the same folder as `index.html`.
4. Open `index.html` in any modern web browser.

- Font Awesome Icons

## 📸 Output

The webpage displays:

- Profile Card UI
